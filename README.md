# Подворье Оптиной пустыни в Санкт-Петербурге — досье

Собрано: 29 августа 2026 г. Тема: Успенская церковь (подворье Оптиной пустыни) на Васильевском острове,
наб. Лейтенанта Шмидта, 27/2. Архитектор — В. А. Косяков.

### Исходные материалы (`источники/`)
Сырые загрузки: статьи Википедии (wikitext), страницы официального сайта подворья, walkspb.ru,
«Православная энциклопедия», городские каталоги (citywalls, aquaviva), фильм «Красуйся, град Петров!»,
статья Р. Бикбова.

### Фотографии (`фото/`)
9 современных снимков (Wikimedia Commons) + портрет Косякова + **41 историческая фотография**
из официального альбома подворья (`фото/старые/`), включая старинный план-чертёж подворья,
снимки строительства и катка.

## Быстрый старт для презентации
Открой `ПРОМПТ_KIMI_SLIDES.md`, скопируй промпт (текст под чертой) в Kimi Slides
и приложи файлы из папок `фото/` и `фото/старые/` — либо всю эту папку целиком.
